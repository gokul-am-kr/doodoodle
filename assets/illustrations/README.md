# Original website illustrations

The seven SVG illustrations in this folder were drawn directly for this site, replacing the decorative SVGs copied from the reference project. They use original paths, black pen contours and the site's yellow, pink, mint and blue accents.

- pencil-comet.svg: making a first mark; webinar card.
- breathing-loop.svg: taking a creative pause.
- idea-sprout.svg: growing an idea.
- shape-play.svg: finding possibilities in simple shapes.
- character-pencil.svg: giving a doodle personality.
- story-pages.svg: telling stories; course card.
- making-together.svg: group workshops and shared creativity.

The brand logo, its four original transformations, and the community gallery remain separate from these decorative illustrations.

The About section uses `../instructor/gokul-sketch.png`, created from the existing photo with the built-in image-generation tool (style-transfer). The source photo is retained as an unused source asset. The generation prompt is recorded in `../instructor/sketch-prompt.txt`.
